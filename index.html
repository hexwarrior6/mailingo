为了读信舒服，我们抠出来的细节

没有花哨的噱头，只解决实际看外语邮件时的烦心事

排版还原

原来长什么样，翻完还是什么样

复杂表格、按钮样式与图文混排一律原地保留，彻底告别把整封邮件剥离成纯文本的乱码体验。

版面自适应

宽图和大表，自动贴合窗口宽度

自动给邮件正文注入自适应宽度约束，再宽的海报和报表也不会被撑破，告别难用的横向滚动条。

系统原生机翻

日常邮件，系统自带离线秒翻

直接调用 macOS 原生离线引擎，毫秒级响应，邮件内容不出你的电脑，也不用掏任何 API 额度费用。

大模型深度精翻

长篇合同与复杂信件，像真人写的

遇到长信或专业外语，可随时切换大模型，深入理解上下文语境与专业术语，告别生硬死板的机翻味。

图片文字翻译

连图里的外语，也能直接原地换掉

自动识别邮件内嵌海报、截图与签名档中的外文，原地覆盖替换渲染，读图顺畅，不用再掏出手机识别。

智能引用折叠

折叠长串旧历史，只看刚回的那句

自动识别多轮历史回复并折叠收起，只把精力花在对方新发的内容上，不再重复翻译昨天的旧废话。

怎么开始用

整个过程大概只需要一分钟

1

拖进 Applications 目录

打开下载好的 Mailingo.dmg，顺手把图标拖进系统的「应用程序」文件夹。

2

彻底重启一次 Apple Mail

按 ⌘Q 完全退出系统 Mail 后重开，进入「设置」(`⌘,`) → 切换到「扩展」标签页。

3

勾上 Mailingo

勾选扩展后回到任意一封外语邮件，阅读窗口顶栏就会自动出现我们的翻译横幅。

几个可能会关心的问题

第一次打开，系统提示无法验证或打不开？

这是因为个人开源软件没有走苹果每年 99 刀的商业认证。只需要打开系统自带的「终端」应用，贴上这行回车跑一下就好：

xattr -cr /Applications/Mailingo.app

平时会在后台挂着吃内存耗电吗？

完全不会。读完邮件点红叉把窗口关掉，整个进程就直接退干净了。Mac 内存寸土寸金，我们不搞任何后台驻留守护。
